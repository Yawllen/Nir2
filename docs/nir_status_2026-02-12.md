# Зафиксировано по состоянию на 12.02.2026

## Зафиксировано

- Контур управления: **MKS Robin Nano V1.2 + Raspberry Pi 3 Model B Rev 1.2 + USB-камера Sonix USB 2.0**.
- Линия связи MCU: **UART PA9/PA10** (legacy USB сохранялся на этапе миграции).
- Драйверы шаговых: **TMC2209**, в текущем конфиге используются в режиме **standalone** (без `[tmc*]`, без `run_current`).
- `microsteps`: **16** по осям X/Y/Z/E.
- Питание: применялся БП **24V/10A**, выполняется переход на **24V/15A**.
- Нагрузки по контурам:
  - **24V**: стол, хотэнд, вентиляторы, шаговые, **MKS Robin Nano V1.2**.
  - **5V**: логика хоста и USB-камера.
- Программные защиты реализованы:
  - лимиты температур хотэнда и стола;
  - `min_extrude_temp`;
  - `verify_heater` для стола;
  - ограничение стола `max_power: 0.50`;
  - verify-проверки по MCU/сервисам.
- Фактически выполненные проверки: smoke/verify-контур (сервисы, API, MCU-error scan, камера).
- Зафиксированные классы сбоев:
  - ошибки связности MCU до прошивки/переключения;
  - `Move out of range` при геометрии/координатах;
  - нестабильности на этапе сборки/окружения.
- Подтверждающие артефакты:
  - репозиторий: `klipper/`, `loader/`, `docs/`, `firmware/rn12/ROBIN_NANO.bin`;
  - логи: `/home/pi/printer_data/logs/klippy.log`, логи crowsnest;
  - кадры печати: `/home/pi/treed/cam/prints`;
  - сборочный бинарник: `~/klipper/out/ROBIN_NANO.bin`.
